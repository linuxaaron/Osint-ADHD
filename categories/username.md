# Username OSINT

Username research is often the fastest route from one public identifier to a broader digital footprint.

## Recommended starting points

- https://whatsmyname.app/
- https://github.com/sherlock-project/sherlock
- https://namechk.com/
- https://keybase.io/
- https://sylva.pfeister.dev/

## Workflow

1. Normalize spelling, case and separators.
2. Test the exact identifier before generating variants.
3. Record positive and negative results with timestamps.
4. Treat a username match as a lead, not proof of identity.
5. Correlate using independent attributes such as biography text, public links, profile imagery or repository history.

## OPSEC

Automated username checks can generate requests to many external services. Review the tool's implementation and provider terms before using it in a sensitive investigation.
