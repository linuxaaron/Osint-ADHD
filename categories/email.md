# Email OSINT

Email addresses can act as stable identifiers across public datasets, services and code repositories.

## Resources

- https://hunter.io/
- https://www.osint.industries/
- https://github.com/laramies/theHarvester
- https://github.com/mxrch/GHunt

## Workflow

- Preserve the exact address and domain.
- Separate domain-level findings from mailbox-level findings.
- Check public sources before active interaction.
- Correlate with independent evidence.
- Never interpret an email-provider lookup as proof that a person owns the associated account without corroboration.
