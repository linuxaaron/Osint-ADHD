# Code & GitHub OSINT

Public repositories can expose project history, identities, infrastructure references, dependencies and development timelines.

## Resources

- https://github.com/
- https://github.com/mxrch/GitFive
- https://github.com/laramies/theHarvester

## Workflow

- Search repositories, users, commits and issues independently.
- Inspect history, not only the default branch.
- Treat email addresses and names in commits as identifiers requiring corroboration.
- Never publish secrets discovered during research.
- If a credential or token is encountered, stop using it and follow the appropriate disclosure process.
