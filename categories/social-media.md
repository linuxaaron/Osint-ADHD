# Social media OSINT

Social platforms are high-volume sources where context and provenance matter more than raw hit counts.

## Approach

- Search exact usernames first.
- Preserve profile URLs and timestamps.
- Compare profile biographies, public links and historical context.
- Treat copied or recycled profile data as potentially stale.
- Avoid creating interactions solely to obtain information when passive sources answer the question.

Start from the [username](username.md) category and the generated upstream index for platform-specific resources.
