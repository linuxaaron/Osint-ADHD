# People OSINT

People-search resources can contain sensitive personal information. Use them only for legitimate, lawful purposes and minimize collection.

## Method

1. Start with non-sensitive identifiers.
2. Confirm identity using multiple independent attributes.
3. Avoid publishing personal data that is not necessary for the research objective.
4. Record the source and retrieval time.
5. Treat data-broker results as potentially inaccurate or stale.

For public identity correlation, begin with [username](username.md) and [email](email.md) research before escalating to broader people-search sources.
