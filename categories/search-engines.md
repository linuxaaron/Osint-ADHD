# Search engines & dorks

Search engines remain one of the highest-value passive OSINT sources.

## Method

- Use exact phrases for distinctive strings.
- Narrow with `site:` and document-type filters where supported.
- Separate discovery from verification.
- Preserve the exact query and result URL when findings matter.
- Re-run important searches later because indexes change.

Google-dork entries from the upstream dataset are marked there as such. Search-engine results are not authoritative evidence by themselves.
